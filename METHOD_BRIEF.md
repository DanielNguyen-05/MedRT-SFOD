# Proposed Method — RASP-SFOD

**RASP-SFOD (Reliability-Aware Structured Pruning for Source-Free Object Detection)** preserves the original RT-SFOD Mean-Teacher framework while making only the Student adaptively lightweight. Teacher and Student start from the same Stage-1 checkpoint. The Teacher remains dense and produces DHF pseudo-labels from weak target views. The Student keeps dense latent weights for EMA compatibility but applies structured hidden-channel gates during strong-view training.

Instead of assigning a fixed pruning rate, RASP learns the pruning structure from unlabeled target data. Bottleneck hidden channels are treated as physically exportable pruning units and can be audited by DepGraph. Target-domain Taylor sensitivity measures channel importance from the existing detection+MARD loss. A per-block GMM detects statistically separable low-importance channels. Candidate channel packs are globally ranked by information loss relative to MAC savings, and a knee detector estimates the current efficient pruning frontier. Pruning is activated only when DHF pseudo-label confidence is sufficiently reliable, then paused for several epochs so continued RT-SFOD/MARD training can implicitly recover from the capacity loss. Importance and the pruning frontier are re-estimated after every cycle.

After adaptation, the accepted masks are converted into a physically compact YOLO26 Student by slicing Bottleneck `cv1` output channels, corresponding BN states, and matching `cv2` input channels. The compact model is numerically checked against the masked Student before Params/FLOPs/latency are reported. Quantization is intentionally excluded from Phase 1 and should be added only after pruning is validated.
