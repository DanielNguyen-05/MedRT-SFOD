# MedRT-SFSeg project page

Static project page for *Directional Dual-Head Supervision for Real-Time Source-Free Polyp Segmentation*.

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Publish with GitHub Pages

1. Create a repository (for example `medrt-sfseg.github.io`, or any repository with Pages enabled).
2. Copy the contents of this folder to the repository root and push.
3. In **Settings → Pages**, deploy from the `main` branch, root folder.
